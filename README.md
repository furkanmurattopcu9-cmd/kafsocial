# FMT Visual — Website Preview

A lightweight, responsive single-page website for FMT Visual, a web design and 3D visualization studio.

## Design direction
- Light, airy backgrounds with restrained charcoal contrast
- Ice blue accent: `#8EDCFF`
- No external JS libraries, web fonts, or remote image dependencies
- Lightweight entrance and scroll-reveal transitions with reduced-motion support
- Responsive mobile navigation
- Concept portfolio pieces are explicitly labelled as concepts

## Before launch
- Connect a real contact email or secure form endpoint. The current form only prepares/copies a project brief in the browser.
- Confirm package scope and pricing.
- Attach the chosen domain and review legal/privacy requirements before collecting real user information.
- This is an isolated preview branch; it does not modify the KAF Social production branch or its domains.
